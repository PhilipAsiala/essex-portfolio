# University of Essex portfolio

Philip C. Asiala. The record of my postgraduate study at the University of Essex: one entry per module, the artefacts each produced, and a reflection written at the end of each. It is kept in git so that every claim about what I learned points at a dated, reviewable artefact.

The research this study supports is public and lives in its own repositories:

| Repository | Role |
| --- | --- |
| [moepa-thesis](https://github.com/PhilipAsiala/moepa-thesis) | Working prospectus: commitment function, chapter outline, the claim that strategy lives in the ledger |
| [moepa-cognitive-architecture](https://github.com/PhilipAsiala/moepa-cognitive-architecture) | Reference architecture and enterprise capability catalog |
| [moepa-profile](https://github.com/PhilipAsiala/moepa-profile) | JSON-LD 1.1 / RDF 1.2 profile for the MOEPA record |

## Layout

| Directory | Holds |
| --- | --- |
| [`modules/`](modules/) | One page per module: aims, what was submitted, grade or feedback once received, and links into `artefacts/` |
| [`artefacts/`](artefacts/) | The work itself, one directory per artefact (reports, code, notebooks, presentations). Large or confidential items are referenced, not copied. |
| [`reflections/`](reflections/) | One reflection per module, written after the result, on what changed in how I think, not on the grade |

## Conventions

- A module page is created the week the module starts and is finished the week the result arrives. Nothing is backfilled without saying so.
- Artefacts are committed as submitted. Later corrections are new commits, so the submitted version remains visible.
- Material that belongs to the University, a tutor, or another student is linked or summarised, never copied in.
- Anything that becomes part of the thesis is moved to the research repositories and linked back from here.
