# University of Essex e-portfolio

Philip C. Asiala. Published with GitHub Pages at <https://philipasiala.github.io/essex-portfolio/>.

Follows the University's e-portfolio guidance: an About Me page; a page per module with learning outcomes, artefacts and feedback, a reflective piece, meeting notes, and a professional skills matrix and action plan; plus a cumulative skills record. Written in Markdown and built by Jekyll (theme `minima`); no local toolchain is needed to publish, a push to `main` is enough.

| Path | Holds |
| --- | --- |
| `index.md` | About me |
| `modules/index.md`, `modules/NN-*.md` | Module list and one page per module; `modules/TEMPLATE.md` is the starting point for each |
| `skills.md` | Professional skills matrix and action plan across the programme |
| `artefacts/NN-*/` | The work itself, committed as submitted, each with a README |
| `_config.yml` | Site title, navigation, theme |

## Conventions

- A module page is created the week the module starts and is finished the week the result arrives. Nothing is backfilled without saying so.
- Artefacts are committed as submitted. Later corrections are new commits.
- Material that belongs to the University, a tutor, or another student is linked or summarised, never copied in.
- Anything that becomes part of the thesis is moved to the research repositories and linked back from here.

The research this study supports is public: [moepa-thesis](https://github.com/PhilipAsiala/moepa-thesis), [moepa-cognitive-architecture](https://github.com/PhilipAsiala/moepa-cognitive-architecture), [moepa-profile](https://github.com/PhilipAsiala/moepa-profile).
